# Pokémon Quiz

Quiz sobre as cores das versões shiny: 10 perguntas, 3 bônus liberados com 100% de acerto e encontros raros opcionais.

## Jogar localmente

Requer PHP 8 ou superior com a extensão `mbstring`. Na raiz deste repositório:

```sh
php -S localhost:8000 -t PW2/pokemonQuiz
```

Abra http://localhost:8000. O progresso da partida usa a sessão do PHP. Sprites de Pokémon são carregados do Pokémon Database e precisam de acesso à internet.

## Hospedagem

Este projeto precisa de uma hospedagem que execute PHP. O GitHub Pages serve arquivos estáticos e não executa o quiz.

Projeto de fã para fins de aprendizado, sem vínculo com a marca Pokémon.
