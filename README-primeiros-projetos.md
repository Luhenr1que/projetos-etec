# Primeiros Projetos

Repositório contendo os principais projetos de estudo e aprendizado em programação web, bancos de dados e desenvolvimento.

## Conteúdo

### PW1 - Programação Web 1
Projeto principal: **Açaí do Clodo**
- Site completo com HTML, CSS e JavaScript
- Páginas finalizadas com design responsivo
- Funcionalidades interativas implementadas

### PW2 - Programação Web 2
Múltiplos projetos em PHP:
- **pokemonQuiz**: Aplicativo de quiz sobre Pokémon
- **Helpdesk**: Sistema de suporte técnico
- **Guaraná**: Projeto sobre a bebida Guaraná
- **OrdemServiço**: Sistema de gerenciamento de ordens de serviço

### Site-Proprio
Site pessoal com múltiplas páginas:
- index.html - Página inicial
- formulario.html - Formulário de contato
- horarios.html - Horários
- lista.html - Listagens
- Imagens e estilos CSS

### Banco-Dados
Projetos de Banco de Dados II com múltiplos esquemas SQL:
- **bdEmpresa.sql** - Banco de dados para gestão de empresa
- **bdEscola.sql** - Banco de dados para gestão escolar
- **bdLojaRoupa.sql** - Banco de dados para loja de roupas
- **Lanchonete.sql** - Banco de dados para gerenciamento de lanchonete
- Projetos adicionais em pastas (livraria, vilaChaves)

## Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP
- **Banco de Dados**: SQL Server / MySQL
- **Ferramentas**: Git, Visual Studio Code
