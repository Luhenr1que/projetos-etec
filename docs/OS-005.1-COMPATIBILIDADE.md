## Configuração comum e diferenças

Expo/RN e dependências permanecem isolados por pasta. SDKs 53 (Termo, Agenda, ZooKids e template), 54 (MedLive completo), 52 (Horóscopo). Saída web SPA com Metro; cada app tem HTML, scripts, favicon e bundle próprios. `experiments.baseUrl` usa o caminho aprovado na produção e pode receber `DEMO_BASE_PATH`. O Vite do portfólio não importa esses bundles.

React Navigation em Agenda/ZooKids/MedLive usa `linking.web.js` com `config.path` para o subcaminho e mapa de telas; `linking.js` mobile deixa a navegação original sem alterações de deep linking. O template usa Expo Router. MedLive define Home como rota inicial na configuração web para permitir voltar após abrir diretamente uma tela. Termo e Horóscopo são telas únicas, sem mapa de rotas internas.

Favicon, JS, CSS, imagens e fontes são exportados com prefixo. Testes monitoram requests fora do prefixo e respostas com erro; decodificam imagens renderizadas e verificam falhas de fontes. O servidor de integração serve o index de cada SPA em rotas sem extensão e retorna 404 para assets ausentes, sem mascarar 404 com HTML. O prefixo é configuração de build: mover um dist compilado para outra base sem reconstruí-lo não é suportado.
